파이널 택틱스 실행 보정 런처
==============================

이 런처는 한국어 Windows판 파이널 택틱스를 최신 Windows에서 실행하기 위한 보정 도구입니다.

게임 본편은 포함되어 있지 않습니다. 사용자가 직접 보유한 원본 매체 또는 설치된 게임 폴더가 필요합니다.

해결하는 증상
------------

- 시작 직후 영상/코덱 초기화 문제
- 초반 이벤트 진행 정지
- 이벤트 대사 직후 클릭 선입력
- 최신 Windows의 화면/속도/DPI 호환성 문제

런처 기능
---------

- 게임 폴더 선택
- 해상도와 표시 모드 설정
- FPS 제한 설정
- DPI 처리 설정
- 설정 적용 후 실행
- 원본 복구
- 남은 게임 프로세스 정리

사용 방법
---------

1. FinalTacticsLauncher.exe를 실행합니다.
2. 게임 폴더에 파이널 택틱스가 설치된 폴더를 선택합니다.
3. 원하는 화면 설정을 고릅니다.
4. 적용 또는 실행을 누릅니다.

처음 실행하면 런처와 같은 폴더에 FinalTacticsLauncher.ini가 생길 수 있습니다.

복구
----

원본 복구 버튼을 누르면 런처가 적용한 FT.exe 패치와 런처가 생성한 호환성 파일만 되돌립니다.
기존 호환성 래퍼 파일, 음악 폴더, 게임 설정은 자동 삭제하지 않습니다.

주의
----

- 이 배포물은 Final Tactics / Elemental Arts 게임 파일을 포함하지 않습니다.
- 음악 파일은 원본 매체 또는 사용자가 가진 설치본에서 준비해야 합니다.
- 포함된 제3자 구성요소는 THIRD_PARTY_NOTICES.txt를 확인하세요.
